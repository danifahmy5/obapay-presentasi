Penjelasan API Peresepan: Interoperabilitas Dua Arah

Integrasi data E-Resep berbasis REST API Sanctum antara sistem ERM rumah sakit dan ObaPay untuk sinkronisasi resep, monitoring status, dan katalog obat.

01 • SINKRONISASI

1. Sinkronisasi Resep

ERM dapat melihat data resep, detail obat, racikan, dan aturan pakai dari ObaPay.

02 • MONITORING

2. Monitoring Status Farmasi

Dokter dapat memantau progres pelayanan resep secara real-time, mulai dari telaah hingga obat diserahkan kepada pasien.

03 • MANAJEMEN

3. Manajemen Resep

Mendukung penyalinan resep kunjungan sebelumnya serta pembatalan resep dengan validasi otorisasi.

04 • MASTER OBAT

4. Integrasi Master Obat

ERM dapat mengakses katalog obat, ketersediaan stok, status formularium, dan informasi DDD.
